# Project Rules

## AI Development Rules

1. Always use React functional components and Hooks for new components.

2. Every form must validate required fields before allowing submission.

3. Test AI-generated code in the browser before committing changes.

4. Keep styling in CSS files instead of inline styles whenever possible.

5. Use Conventional Commit messages for every Git commit (for example: feat:, fix:, docs:, refactor:).

6. Review AI-generated code manually before accepting it to catch UI and logic issues.
